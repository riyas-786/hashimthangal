Conifer Decore LLP website
==========================

Folder structure
  index.html      the website (one page: overview, Conifer uPVC, Pengeluar, quote form)
  css/style.css   all styling
  js/main.js      product cards, share buttons, quote form
  images/         all photos used on the site
  favicon.svg / favicon.png / apple-touch-icon.png   browser tab icons

How to host
  Upload the CONTENTS of this folder (index.html, css, js, images and the
  favicon files) to the root of your hosting (public_html / www / htdocs),
  keeping the folders as they are. Works on any normal host, including
  Netlify, Vercel, GitHub Pages and cPanel hosting. No database or build
  step needed.

Things you can edit
  Phone / WhatsApp / email: search index.html for 919961707498 and
  coniferdecore@gmail.com (the quote form also uses them in js/main.js).
  Product cards and specifications: the lists at the top of js/main.js.
  Colours: the variables at the top of css/style.css.

Note: the fonts load from Google Fonts, so an internet connection is needed
for the intended typefaces; the site falls back to system fonts without it.
